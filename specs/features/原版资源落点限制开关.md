# 原版资源落点限制开关 — 功能需求说明书

## 1. 背景与价值

**为什么做**：部分玩家希望资源种植遵循《文明 VI》原版资源落点表，例如海龟只能种在允许海龟生成的地貌上。

**做成什么样**：在高级设置中提供一个默认关闭的开关，让玩家自行选择宽松种植或原版资源落点限制。

---

## 2. 范围

### 本次做

- 在高级设置中增加“遵循原版资源落点限制”开关，默认关闭。
- 开启后，仅显示并允许种植符合原版资源落点规则的资源。
- 对最终种植请求再次校验，避免绕过界面限制。

### 本次不做

- 不改变森林、雨林等地貌的种植规则。
- 不增加逐资源或逐玩家的独立设置。

---

## 3. 用户与故事

**涉及角色**：创建游戏的玩家、游戏中的玩家

| 编号 | 用户故事 | 关联 AC |
|------|---------|---------|
| US-001 | 作为创建游戏的玩家，我想选择是否遵循原版资源落点限制，以便按偏好的规则游玩 | AC-001, AC-002 |
| US-002 | 作为游戏中的玩家，我希望资源选择列表与实际种植结果一致，以免浪费建造者充能 | AC-003, AC-004 |

---

## 4. 需求详述

### 4.1 核心流程

1. 玩家在高级设置中选择是否启用原版资源落点限制。
2. 游戏中打开建造者种植入口。
3. 选择器只显示当前规则下可种植的资源，成功后留下真实资源。

### 4.2 交互规则

- 开关默认关闭，以保持模组现有行为。
- 开启时，不符合当前地块原版落点规则的资源直接隐藏。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | 开关只影响资源种植，不影响地貌种植。 |
| BR-002 | 开启后，界面候选项和最终种植都必须遵循原版资源落点规则。 |
| BR-003 | 关闭后，继续只按现有陆地/海洋及通用安全规则限制资源种植。 |

---

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 默认保持宽松种植
  - **Given** 玩家创建新游戏且未修改新增开关
  - **When** 玩家查看高级设置并进入游戏种植资源
  - **Then** 开关显示为关闭，资源仍按现有宽松规则提供

- [ ] **AC-002**: 开启原版限制
  - **Given** 玩家在高级设置中开启原版资源落点限制
  - **When** 玩家在符合某资源原版落点规则的格子上打开种植入口
  - **Then** 该资源可见且可以成功种植

- [ ] **AC-003**: 隐藏不合法资源
  - **Given** 原版资源落点限制已开启
  - **When** 玩家在不符合某资源原版落点规则的格子上打开种植入口
  - **Then** 该资源不出现在选择列表中

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-004**: 拒绝绕过界面的非法请求
  - **Given** 原版资源落点限制已开启且目标资源不符合当前格子规则
  - **When** 游戏收到该资源的直接种植请求
  - **Then** 资源不会落地且不会消耗建造者充能

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-005**: 地貌规则不受影响 ← BR-001
  - **Given** 原版资源落点限制处于任意状态
  - **When** 玩家种植森林或雨林
  - **Then** 可选项和结果仍遵循现有地貌规则

- [ ] **AC-006**: 开关关闭时兼容旧行为 ← BR-003
  - **Given** 原版资源落点限制已关闭
  - **When** 玩家在同陆海域但不符合资源原版落点规则的合法格子上种植资源
  - **Then** 资源仍可显示并成功种植
